# reporting

**Stratum 4** | **Python 3.12** | **Built by WP-17**

Daily position, movement summaries and regulatory extracts, generated from the ledger. Batch, not real-time, because that is what reporting genuinely is.

**Reports must be reproducible**: rerunning for a historical date produces identical output. A report built on mutable state is not auditable, and auditability is the entire purpose. Reports carry account references, never personal data.
