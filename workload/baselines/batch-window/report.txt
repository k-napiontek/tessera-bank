== What the sorts cost, which is a property of this stand-in and not of the tier ==
  STEP010 and STEP030 are sortrec.py, which reads the whole file into a list. DFSORT
  spills to work datasets and does not. STEP020 is ACCTPOST, which match-merges two
  sorted files in one pass and never holds the master in memory - the property the tier
  exists to demonstrate. Read the two apart.

  The writer figure is this fixture's own ceiling and not the cycle's: generate.py
  --from-stream holds the whole day as Python objects before it writes a byte. It is
  reported because it is what decides how large a day can be prepared on a given
  machine, and it is the larger of the two.
